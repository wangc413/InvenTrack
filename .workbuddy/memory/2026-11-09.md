## 库存页/数据页白屏修复（重要 Bug）
- 症状：库存页、数据页（数据中心）白屏，装车/记录/档案正常。
- 根因①：用 Python 批量生成 95 个 sku 时数组末尾多了一个逗号 `}),,`，产生数组空洞（undefined 元素），导致 `todayFlow()` 里的 `new Map(db.skus.map(...))` 抛 `TypeError: Iterator value undefined is not an entry object`。已删多余逗号。
- 根因②：历史损坏数据（含 null/undefined 的 sku/customer/batch/move）在 migrate 时未过滤，会再次触发同类 `new Map` 崩溃。
- 修复：migrate 里对 customers/skus/batches/moves 加 `filter((x)=>x && typeof x==='object' && x.id)` 兜底；`todayFlow`(store.ts) 和 `buildShipLines`(xlsx.ts) 的 `new Map` 前加 `filter((s)=>s&&s.id)` 双重保险。
- 验证：注入含 null sku/customer 的损坏数据，库存页/数据页均正常渲染无异常。
- 用户仍需清一次 WorkBuddy 内置浏览器的站点数据（IndexedDB 里已有损坏数据），或依赖 migrate 过滤自动修复。
