## 箱面改成真实外箱设计稿（快乐猴五个品）

用户给了四份外箱刀版稿 PDF（`D:/deskbox/room/仓库/箱子包装/快乐猴/`），要求 3D 箱子按真实包装画。

- **刀版结构**：一页里躺平四个面板 = 正面(L×H) / 侧面(W×H) / 背面(L×H) / 侧面(W×H)，
  上面一条是四个摇盖，**每个摇盖进深恰好 W/2**。包子稿一页有上下两套（上=菜包、下=肉包）。
- 坐标靠 `page.get_drawings()` 里的大矩形反推（`rect.width>600 and height>300`），
  不必人工量像素：x 给 5 个面板边界，y 给 flap / body 两段。
  反推结果与标题标注的外径完全吻合（包子 500×340×220、菜团子 445×350×270、饺子 430×300×230、糯米鸡 400×345×235）。
- **顶面拼法**：three 的 +y 面 v=1 在 -z 侧，所以上半张放后摇盖（转 180°）、下半张放前摇盖，
  合盖后的样子和真箱一致（一半品名、一半贮运图标，图标是倒的）。
- 产出 `src/assets/pack/klh-{meat,green,cai,jiao,nuo}-{front,side,top}.webp`，15 张共 ~500 KB。
- `box3d.ts`：新增 `PACK_ART`（sku.id → 三张 URL）+ `artTexture()`（sRGB + anisotropy 4）；
  `assetFor` 从 2 组材质改成 **4 组**：`0 ±x 侧面 / 1 +y 顶面 / 2 -y 底面素色 / 3 ±z 正面背面`，
  `mats = [side, top, bottom, front]`。盒马那三个没有稿子，仍走原来的示意箱面（matFront === matSide）。
- 沉淀了 `tools/pack-textures.py`：按刀版坐标裁三张图，参数化，重跑与仓库里的贴图逐像素一致。
  以后盒马的外箱稿到了，量四条竖线 + 两段 y 就能出图。

### 验证（CDP 无头 390×844）
快乐猴五品逐个装板：肉包/菜包/菜团子/饺子/糯米鸡 箱面分别显示对应设计稿，
转 90° 的箱子长面朝外、文字跟着转（物理上对）；顶面一半品名一半图标；
整车 2 板（肉包 49 箱 + 饺子 4 层 40 箱）两块板箱面不串味；盒马烧麦仍是示意箱面，没被改坏。

## 盒马三个品也换成真实外箱稿（当天下午）

用户："盒马的箱子也重新画，太粗糙了"。盒马的稿子其实一直在
`D:/deskbox/room/仓库/箱子包装/盒马/`（鲜汁大肉包外箱.pdf / 青菜包外箱.pdf / 烧麦外箱转曲.pdf），
只是之前没接进去。走的是同一套 `tools/pack-textures.py`：

- 刀版结构跟快乐猴一致：一排 4 块面板（L / W / L / W）+ 上面一条摇盖（进深 = W/2）。
  - 肉包 `--flap 479.5,954.3 --body 954.3,1492.9`，`--xs 174.5,1591.9,2541.5,3958.8,4908.4`
  - 青菜包 `--flap 483.6,965.5 --body 965.5,1532.4`，`--xs 251.6,1668.9,2632.7,4050.0,5013.8`
  - 烧麦 `--flap 201.3,789.5 --body 789.5,1455.6`，`--xs 0.3,1318.4,2494.8,3812.9,4989.2`
- **烧麦稿是三行**（摇盖 / 箱身 / 另一组摇盖），中间那行才是箱身；上下两行都是摇盖（各 588pt ≈ W/2）。
  正文是转曲的（没有文本层），但刀版矩形照样读得出来。
- 产出 `src/assets/pack/hm-{meat,green,shao}-{front,side,top}.webp`，9 张；`PACK_ART` 里加
  `sku-meat / sku-green / sku-shaomai` 三条，走同一套 4 组材质（±x 侧面 / +y 顶面 / -y 底面 / ±z 正背面）。
- `artTexture` 的 anisotropy 4 → 8，斜着看时箱面小字更清楚。
- 顺手把「没有稿子」的兜底箱面重画了一遍（`faceTexture` / 新增 `sideTexture` / `topTexture`）：
  牛皮底 + 纤维噪点、正面底部品牌色带 + 品名大字 + 规格 + 「速冻面米制品 / -18℃ 冷藏」，
  侧面缩小的品名 + 配料表灰字 + 条码 + 规格，顶面摇盖中缝 + 品名 + 「此面朝上」。
  踩坑：配料表行数原来按 H/26 硬算，小箱身会写过头压到条码和品名上——改成先定条码位置，
  再按剩余高度算行数。材质参数对象原名 `paper` 跟新加的 `paper()` 函数重名，改名 `papery`。
- `tools/pack-textures.py` 头部把八份稿的完整命令参数都记下来了（盒马 3 条 + 快乐猴 5 条），
  重跑时照抄即可；实测按这些参数重跑，快乐猴贴图与仓库里的逐像素一致（水饺正面差 1px，是 y1 取整）。
